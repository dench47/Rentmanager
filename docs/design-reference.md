## Общие правила

- Иллюстрации — PNG 5x в `drawable-nodpi` + `FilterQuality.High`;
  мелкие линейные иконки — VectorDrawable (конвертер tools/svg2vd.py, альфы
  обязательны);
- Экспорт иконок из Figma — только по ID инстанса `I<frame>%3B<component>`
  (по компоненту отдаёт мусор: «корона»/«колокол» вместо нужного);
- lineHeight: 15sp→18.2, 13sp→15.7 явно;
- Обновление этого файла обязательно при новых звёздах Вики.

## Шевроны (зафиксировано Денисом 2026-09-21)

**ВСЕ шевроны в приложении — наш кастомный `ic_card_chevron`** (40×40, глиф

## Каноны экранов (зафиксировано Денисом 2026-09-22)

- **Заголовок экрана всегда нажимаем: тап по названию = тап по стрелке «назад»**
  (вся строка стрелка+название — один кликабельный блок).
- **Тапбар с CTA (низ экрана редактирования)**: панель #EDEDED@90%,
  **верхние углы скруглены 30**, поля 20/10; кнопки СТАТИЧНЫ — клавиатура
  их НЕ поднимает (никакого imePadding на тапбаре), контент скроллится под ней.
- **Баяны по умолчанию ЗАКРЫТЫ** — раскрывает только юзер; шеврон всегда наш
  ic_card_chevron (180° при раскрытии).
- **Паспортные поля в редактировании** — три состояния: пустое (подпись 15/600
  серым в 2 строки, глаз-слэш) / видимое (подпись 13/400 + значение, глаз) /
  скрытое (маска «·· 08»/«······2545», глаз-слэш); глаз переключает видимость.

- **Клавиатура не должна прятать поле ввода** (канон 2026-09-22): `imePadding`
  вешается ТОЛЬКО на скроллящийся контент (вьюпорт сжимается до клавиатуры,
  Compose сам докручивает к полю в фокусе); тапбар с CTA остаётся неподвижным.
- **Числовые поля** (паспорт и т.п.) открывают числовую клавиатуру
  (`KeyboardType.Number`).
- **Пункты меню/шитов всегда рабочие** — «не для красоты написаны»: Сфотографировать
  → TakePicture (FileProvider), Выбрать из галереи → GetContent(image/*),
  Выбрать файл → OpenDocument.

## Документы: черновик-стейдж и подтверждения (зафиксировано 2026-09-23, аннотации Вики)

- **Аннотация 2983:45668 «Поведение кнопок»** — после «Отменить и выйти»: ранее сохранённые
  данные восстанавливаются, **добавленные файлы НЕ прикрепляются**, **документы, отмеченные
  для удаления, сохраняются**, пользователь возвращается в режим просмотра карточки.
  Значит документы — ЧЕРНОВИК: загрузка + прикрепление/удаление только по «Сохранить изменения».
  Нижние CTA активны при ЛЮБОМ изменении — поля ИЛИ добавленные/помеченные документы.
- **«Отменить изменения?» (2983:45634)**: 380 r20, pad 20, зазор 10 — заголовок 20/600 + 6 +
  подпись 15/600 lh 18.2 #727272 («Внесенные изменения не сохранятся. Вы вернетесь к сохраненной
  карточке арендатора», перенос естественный) + 20 → чёрная «Продолжить редактирование» + 6 +
  контурная «Отменить и выйти». Показывается при выходе с несохранёнными изменениями
  (тапбар «Отменить изменения», стрелка/заголовок «назад»).
- **«Изменения сохранены» (2983:42825)**: окно 380×124 r20 pad 20 зазор 10 — иконка успеха 50
  + текст 20/600; аннотация 2983:44755: «короткое подтверждение и возвращаемся к состоянию
  просмотра карточки» (после подтверждения — назад в карточку).
- **Ошибки** загрузки/прикрепления/сохранения — окно с глобусом (`IconNotificationDialog`,
  `ic_globe_warning_vec`, зазор 12): «Не удалось прикрепить документ. \nПовторите еще раз»,
  «Не удалось сохранить изменения. \nПовторите еще раз». Немые `runCatching` без окна — нельзя.
- **КАМЕРА: `uses-permission CAMERA` из манифеста УДАЛЕНО (2026-09-23).** Если приложение
  объявляет CAMERA, но не имеет её (и не запрашивает), MIUI/Android отказывает в запуске
  ACTION_IMAGE_CAPTURE — «Сфотографировать» молча не открывал камеру. Приложение камеру само
  не использует (делегирует системной) → разрешение не нужно; не возвращать, пока не появится
  реальная работа с Camera2/CameraX.
